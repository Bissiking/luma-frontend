# Images pour la plateforme Nino

Ce dossier contient les images utilisées par la plateforme Nino.

## Structure recommandée

- **thumb{n}.jpg** : Miniatures des vidéos populaires
- **continue{n}.jpg** : Miniatures des vidéos "Continuer à regarder"
- **recommended{n}.jpg** : Miniatures des vidéos recommandées
- **featured.jpg** : Image de la vidéo mise en avant dans la section héro
- **live-stream.jpg** : Image de la diffusion en direct
- **avatar{n}.jpg** : Avatars des utilisateurs du chat
- **andy-profile.jpg** : Avatar du créateur Andy William

## Note

Assurez-vous que les images respectent les proportions 16:9 pour les miniatures vidéo et sont optimisées pour le web.
